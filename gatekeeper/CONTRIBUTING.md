# Contributing

Keep Gatekeeper as prose describing a portable workflow. Contributions should
improve task decomposition, acceptance criteria, verification, or reporting
without assuming a specific model provider, agent interface, or installation
path.

Preserve observable acceptance criteria and explicit evidence. Do not imply
that the instructions mechanically enforce completion. Explain the failure
mode addressed by a proposed rule and keep the response proportional to it.

Keep supporting references discoverable from the skill. Avoid executable
helpers, fixed output schemas, duplicated instructions, and mandatory record
formats. Retain valid skill names, descriptions, and license attribution.

Validate links and metadata after changes. For substantive workflow changes,
exercise a realistic task when practical and report what was actually
observed. Do not treat matching instruction text as proof of behavior.
