# Coordinate dependent deliverables

Use this approach when a task spans several deliverables, participants, or
sessions. Coordination depends on the task's contracts and evidence, rather
than a particular agent interface.

## Prepare the work

Record the task contract, deliverables, dependencies, ownership, and acceptance
criteria. A deliverable is ready when its dependencies have been verified,
its inputs and criteria are available, and it has not already been completed.

Make concurrent work safe before starting it. Participants must not make
uncoordinated edits to the same artifact. Record an explicit dependency when
ownership passes from one deliverable to another.

## Execute the ready work

When concurrency is supported and authorized, start independent ready
deliverables within the available capacity. Give each participant only the
shared contract, their own scope and criteria, and the context needed to work.
If concurrency or delegation is unavailable, process ready work sequentially.

As results arrive, verify their acceptance criteria against the actual result.
Repeat meaningful checks and inspect evidence requiring judgment. Return
incomplete work with the unmet outcomes named. A completion claim unblocks
nothing until verification succeeds.

After each verified result, update the work record and identify newly ready
deliverables. Where concurrent work is supported, continue independent work
without waiting for unrelated participants to finish.

## Integrate and report

Treat branch integration as its own deliverable after the relevant children
are verified. Check interfaces, combined behavior, and affected related paths.
Reopen outcomes when integration invalidates earlier evidence.

Use independent verification when available or required. Distinguish a
participant's self-check from a separate review. If required independent
verification is unavailable, leave that requirement pending and arrange a
handoff rather than claiming it passed.

Report completion only when root acceptance criteria pass. Identify every
remaining blocker or user-approved waiver and re-measure reported counts.
