# Gatekeeper

Gatekeeper keeps substantial tasks tied to explicit acceptance criteria and
verified evidence. It is a prose workflow for any environment that can read
the skill and perform the checks required by the task.

## Workflow

Record observable outcomes before work begins. Complete focused tasks
directly, or use a Depth Tree to separate larger tasks into deliverables and
integration obligations. Verify results before dependent work relies on them.

Use available project checks and direct observations to establish outcomes.
Keep incomplete criteria visible, reopen failed checks, and distinguish user
waivers from passed validation. Audit the final report against the actual
inventory and measured evidence.

Independent participants and concurrent execution can help substantial tasks,
but the workflow can also be performed sequentially. Required independent
verification remains pending until a separate reviewer is available.
